# Beyond The Sky – VR Solar Exploration

Beyond The Sky is a Virtual Reality (VR) application built in Unity that enables users to explore the solar system through an interactive spaceship interface. The project combines real-time navigation, immersive environments, and guided interaction to create an engaging exploratory experience.

---

## Overview

This project focuses on delivering an interactive simulation where users can:

* Navigate through space using a controllable system
* Visit and observe different planets
* Experience immersive environments designed for VR
* Receive contextual information through an integrated voice system

The goal of the project is to demonstrate practical skills in Unity development, VR interaction design, and 3D environment creation.

---

## Features

* **Spaceship-Based Navigation**
  A movement system that allows users to travel across the environment.

* **Planet Exploration System**
  Structured transitions enabling users to reach and explore different planets.

* **Voice Assistance**
  Audio-based guidance providing information about celestial bodies.

* **Immersive Environments**
  Includes planetary surfaces, space environments, and interior spaceship views.

* **VR Integration**
  Designed for compatibility with VR devices using Unity XR tools.

## Setup Instructions

1. Clone the repository:

```
git clone https://github.com/aditya-654/Beyond-The-Sky.git
```

2. Open the project using Unity Hub (recommended version: Unity 2022 or later)

3. Connect a compatible VR device 

4. Run the project from the Unity Editor
